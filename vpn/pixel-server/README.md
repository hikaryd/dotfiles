# Компоненты Pixel

Необязательные инструменты: защищённое управление экраном, SSH владельца, браузерная очередь и очистка вкладок.
Установщик VPN их не запускает. [Правила Hermes](HERMES-ACCESS.md), [приватные параметры](PRIVATE-CONFIG.md).

## Управление экраном

Caddy в Termux публикует HTTPS только на выбранном LAN IPv4; droidVNC-NG остаётся на loopback.
Сформируйте приватный `~/pixel-admin/Caddyfile` из `Caddyfile.template` и `control.json` из `control.example.json`.
Подставляйте LAN IP, домашний каталог Termux, имя владельца, bcrypt-хеш и отдельный случайный токен helper без shell eval: символы `$` в хеше должны сохраниться.
Сертификат должен содержать выбранный IP в SAN; доверие проверяется отдельно, `curl -k` его не доказывает.
Сохраняйте точные правила Host/Origin и запрет терминальных маршрутов. Не включайте произвольную раздачу файлов.
Перед запуском: `caddy validate --config "$HOME/pixel-admin/Caddyfile" --adapter caddyfile`.
Пароли панели, VNC и токен helper различны; Hermes их не получает. PIN и защищённые окна Android не обходятся.
Смена конфигурации требует управляемого перезапуска только затронутой службы, не всего телефона/VPS.

## SSH владельца

`ssh-owner/` содержит установщик и супервизор Termux. Настройка и перенос описаны в [приватном инвентаре](PRIVATE-CONFIG.md).
Сервер слушает только loopback и заданный LAN IPv4; обратный порт VPS — только loopback.
Клиент использует личный ключ владельца, проверенные ключи хостов и `ForwardAgent no`.
Не отключайте проверку ключей SSH; закрытые ключи телефона остаются на телефоне. Доступ владельца не выдаётся агенту.
SSH даёт права Termux, не root Android. Сессия tmux переживает обрыв SSH, но не остановку Termux или перезагрузку.

## Другие компоненты

- [Очередь браузера](concurrency/README.md): четыре фоновых чтения, эксклюзивные действия; общие cookies.
- `tab-cleaner/`: отдельная служба и таймер на VPS; включать только с пониманием возрастной политики.
- Очиститель закрывает все страницы, включая активные, через 12 часов от первого наблюдения; проверка каждые 5 минут. Навигация не сбрасывает возраст.
- Повреждённое состояние начинает отсчёт заново; недоступность CDP откладывает закрытие. URL и cookies в состоянии не сохраняются.
- [Общий аккаунт сервисов](shared-openai-account/README.md): отдельная настройка владельца учётных данных.

Тесты не доказывают состояние установленного телефона: отдельно проверяются навигация, прерывание владельцем, восстановление и очистка только принадлежащих задаче вкладок.
