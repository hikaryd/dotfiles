# Приватные параметры Pixel

Храните инвентарь вне Git: `~/.config/pixel-private/` либо игнорируемый `vpn/private/`.
Каталоги — `700`, файлы с настройками/секретами — `600`. [Общий перенос](../../docs/PRIVATE.md).
Установщик VPN эти файлы не читает и телефон не настраивает.

## Что сохранить

- Адрес роутера, зарезервированные LAN IP/MAC телефона, его идентификатор и текущий авторизованный ADB endpoint.
- SSH-адрес VPS и проверенные публичные ключи хостов; личный ключ владельца храните в менеджере ключей.
- Параметры панели: точный Origin, отдельный токен helper, учётные данные владельца и доверенный сертификат.
- Приватные конфиги и способы восстановления доступа; диагностические журналы, cookies и токены не публикуйте.

## Панель и SSH

На телефоне создайте `~/pixel-admin/control.json` по `control.example.json`.
Укажите реальные `lan_ip`, `serial` и случайный токен; `origin` должен точно совпадать с `https://<lan_ip>:8443`.
Используйте тот же IP/токен в `Caddyfile.template`. Не допускайте wildcard bind; сначала проверьте конфигурацию и доверие TLS.

Для SSH заполните приватную копию `ssh-owner/inventory.example.json`: LAN IPv4 и VPS IPv4.
Зарезервируйте LAN адрес до установки. В Termux, из каталога `ssh-owner/`:

```sh
python install.py --inventory "$HOME/pixel-private/ssh-inventory.json"   --owner-key "$HOME/pixel-private/owner.pub"   --vps-host-key "$HOME/pixel-private/vps-host.pub"
```

Установщик сохраняет `~/pixel-owner/inventory.json`, ограничивает bind и закрепляет ключ VPS.
Он отказывается переустанавливать существующий каталог владельца: это не инструмент миграции.
Для клиента используйте `ssh-owner/client.example.conf`; частный файл `config/ssh/pixel-owner.conf` игнорируется Git.
Не выдавайте SSH владельца Hermes и не копируйте закрытые ключи телефона на новый компьютер.

## Существующая установка

Не заменяйте один helper/супервизор без подготовки его приватных входных данных.
Сначала добавьте `lan_ip`/`serial` в существующий `control.json`, сохранив токен/Origin, и подготовьте SSH-инвентарь с прежними bind, адресами и ключами.
DHCP-скрипту нужны явные `ROUTER_HOST` и `--expected-ip`; установщику VPN — адрес роутера.
После проверки применяйте только согласованные изменения конкретной службы. Очистка документации не меняет работающую установку.
