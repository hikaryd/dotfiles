# Правила доступа Hermes к Pixel

## Выбор маршрута

- Для собственного поиска и проверки страниц Hermes использует существующий Pixel Chrome первым.
- По явному требованию пользователя конкретный разрабатываемый сервис может работать независимо через API, HTTP или свой браузер, включая headless: реализация, тесты и работа сервиса не получают скрытой зависимости от Pixel.
- Зафиксируйте такое разрешение в конфигурации/краткой документации проекта; повторно спрашивать в согласованном объёме не нужно. Исключение не меняет правила других проектов и собственного поиска агента.
- Недоступность телефона или удобство сами по себе не разрешают сменить маршрут.
- Российские сервисы, включая сервисы не на `.ru`, работают без дополнительных прокси даже при ошибке. Существующие WG/маршруты не менять. Для остальных ресурсов нужны отдельные действующие разрешения на прокси.
- Не переносить cookies/токены Pixel без отдельного разрешения; не выдавать другой браузер за Pixel.

## Работа через Pixel

Используйте существующий `browser_exec` и настоящий Android Chrome, не запускайте вместо него новый headless.
Открывайте для задачи отдельную вкладку, записывайте её ID, закрывайте только свои вкладки и проверяйте их отсутствие.
Не закрывайте чужие активные вкладки ради памяти. При недоступности CDP допустим ограниченный повтор чтения.
Владелец может прервать туннель управлением экраном; при блокировке нужен ручной PIN, обход запрещён.

## Необязательная очередь

[Очередь](concurrency/README.md) включается отдельно. Повторно используйте `pixel_read_1`–`pixel_read_4`.
Четыре чтения выполняются одновременно, пятое ждёт. Код атомарного чтения целиком:

```text
# pixel:read-v1
{"url":"https://example.org/","max_chars":20000}
```

Каждое чтение создаёт и закрывает свою фоновую вкладку. Клики, ввод и произвольный Python выполняются эксклюзивно.
Для новых интерактивных задач используйте `pixel_ui_<task>`; завершайте вызовом `# pixel:finish-v1` с тем же `session`.
Ответ `preserved_unmanaged` означает, что старая вкладка не закрыта автоматически.
Не обходите очередь параллельными вызовами Playwright MCP или прямого CDP.
Это кооперативный планировщик, не защитная песочница: профиль и cookies общие, изоляции аккаунтов нет.
Приоритет владельца определяется опросом, а не мгновенной блокировкой; не повторяйте прерванные клики/отправки вслепую.
Недоступность CDP не разрешает запуск запасного Chrome или обход правил прокси.

## Границы прав

SSH владельца и его панель не являются доступом Hermes: не запрашивать закрытые ключи, не пробовать чужие пароли и не расширять переадресацию.
Termux имеет доступ к ключам моста; административный shell требует отдельного согласования.
Не включать root, перепрошивку, общий доступ Android, открытый прокси или доступ ко всей LAN автоматически.
Не возобновлять установку гостевых сред на телефоне без нового явного запроса владельца.
Не хранить результаты только во вкладке: необязательная возрастная очистка может закрыть даже активную страницу.
Адреса и параметры установки — только в [приватном инвентаре](PRIVATE-CONFIG.md).
