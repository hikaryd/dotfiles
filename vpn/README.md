# VPN-шлюз

Скрипты настраивают AmneziaWG между роутером и VPS и sing-box для разделения маршрутов.
Нужны Debian/Ubuntu на VPS, SSH по ключу, совместимый роутер Keenetic/Netcraze с HTTP RCI.
На машине запуска: Bash, SSH/SCP, Python 3 и curl; она должна видеть роутер напрямую.

```sh
cd vpn
./install.sh --help
./install.sh
```

Без аргументов установщик запрашивает параметры. Пароли и ссылку подписки не помещайте в историю команд.
Настройка меняет VPS и/или роутер: заранее проверьте выбранные адреса и сохраните резервные копии.
`--skip-router` пропускает роутер; `--skip-vps` использует уже установленный сервер.
Адрес роутера задаётся явно; реальные параметры храните вне Git, например в `vpn/private/` (каталог `700`, файлы `600`).

## Ограничения

- Политика `AWG_LAN` разрешает выбранному LAN-сегменту только туннель, но сам роутер может переключаться на WAN.
- Назначение выбранного сегмента заменяется; другие сегменты и индивидуальные политики не перезаписываются.
- Индивидуальные правила имеют приоритет. IPv6 и отсутствие утечек нужно проверять на конкретном роутере.
- Старые сторонние сетевые хуки автоматически не удаляются; geoip не определяет страну владельца сайта.
- Для повторной настройки только роутера используйте `--skip-vps`; не повторяйте полную установку вслепую после обрыва SSH.

На VPS: конфигурация `/etc/sing-box/vpn.env`, секрет панели `/etc/sing-box/secret.txt`, реестр пиров `/root/awgvpn/peers/`.
Проверка служб: `systemctl status sing-box awg-quick@awg0 awg-gateway`.
Панель слушает HTTP на порту `9090`; не открывайте её в недоверенную сеть без защищённого доступа.

Браузерный телефон для агентов настраивается отдельно в `~/Documents/dev/agent-phone/`;
установщик VPN его не меняет.
[Хранение и перенос секретов](../docs/PRIVATE.md).
