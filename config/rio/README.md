# Rio

Профиль перенесён с чистого Ghostty без iglass. Проверен с Rio 0.5.28 на macOS 26.5.
Ghostty остаётся установленным как запасной терминал.

## Что перенесено

- Тот же `~/.local/bin/dots-nu`, SF Mono 15 и Symbols Nerd Font Mono.
- Общая палитра Ayu, Display P3, эффективная непрозрачность около 0.94, размытие,
  скрытый заголовок. В Rio 0.5.28 на macOS задано `opacity = 0.75`: два фоновых
  слоя дают `1 - (1 - 0.75)² = 0.9375`, как прежние 0.94 в Ghostty.
- `opacity-cells = false` сохраняет цельный цвет скруглённых табов и других
  цветных элементов. Основной фон Herdr остаётся прозрачным: `panel_bg = "reset"`.
  TUI с собственным явным RGB-фоном может остаться непрозрачным.
- Отступы 18 по горизонтали и 14 по вертикали, высота строки 1.12, отключённые лигатуры.
  `navigation.mode = "nativetab"` не резервирует скрытую GPU-панель Rio над Herdr.
- Немигающий синий курсор-луч, скрытие мыши при наборе, затемнение неактивных сплитов.
- Option+Delete, Ctrl+A/H/J/K/L/V/W, Ctrl+Shift+H/J/K/L, Ctrl+1…9.
- Cmd+D: сплит справа. Cmd+Shift+D: сплит снизу. Cmd+Enter: fullscreen.
  Cmd+Shift+P: палитра команд. Остальные сочетания остаются стандартными для Rio.
- В Rift и AeroSpace используется workspace `d`, как у Ghostty.

Конфиг и тема подключаются через `steps/tools.yml`. Чужие существующие файлы
автоматически не перезаписываются. Rio умеет обновлять настройки без перезапуска.
Если редактируешь оригинал в dots, watcher каталога с symlink может пропустить
изменение. Для явного обновления: `touch -h ~/.config/rio/config.toml`.
Тема генерируется отдельно, поэтому обновление палитры не стирает настройки терминала:

```sh
build/bin/dots-tools palette --tool rio --variant dark
# Или более светлый вариант той же палитры:
build/bin/dots-tools palette --tool rio --variant mirage
```

## Если снова появились зазор, непрозрачность или стыки табов

- На macOS режим Rio `tab` резервирует 38 pt даже при `hide-if-single = true`,
  а `plain` оставляет 26 pt. Нужен `nativetab` без unified titlebar. На живом
  Retina-окне начало табов поднялось со 108 до 32 px после смены режима.
- Не копируй числовое `opacity = 0.94` напрямую из Ghostty: в Rio 0.5.28 оно
  даёт почти непрозрачные 0.9964 после наложения фоновых слоёв. Для текущих 0.75
  в оконном PNG без blur измерена альфа `239/255 = 0.9373`.
- Не включай `opacity-cells` ради прозрачности Herdr. Скругления табов рисуются
  символами переднего плана, а середина заливкой ячеек. Полупрозрачная заливка
  делает середину темнее краёв. Нужны непрозрачные UI-цвета и `panel_bg = "reset"`.
- Оконный снимок с включённым blur может подставлять сплошной фон вместо backdrop.
  Видимость обоев проверяется полным снимком экрана, а не только PNG одного окна.
  После исправления проверены и фон за Herdr, и цельные активные/неактивные табы.
- Эти поправки проверены для Rio 0.5.28. После обновления рендерера калибровку
  стоит проверить заново. Статические Go-тесты защищают конфиг, не сам compositor.

## Отличия, которые нельзя перенести один в один

- Ghostty использует physical-клавиши, Rio 0.5.28 в конфиге принимает logical-клавиши.
  Для пользовательских Ctrl-сочетаний добавлены русские алиасы, но произвольная третья
  раскладка не обещается. Модификатор в Rio называется `control`, не `ctrl`.
- У Rio нет прямого числового аналога силы размытия Ghostty `18`.
  Межстрочное расстояние тоже зависит от метрик рендерера, поэтому полного пиксельного
  совпадения ожидать не стоит.
- Профили `dots style` и шейдеры Ghostty не применяются к Rio автоматически.
- Скорость относительно Ghostty не измерялась. Эффекты могут её ухудшать.

## Можно ли добавить красоты

Да. По умолчанию оставлен спокойный вид без анимаций. Следующие варианты встроены
в Rio, устанавливать iglass для них не требуется. Это примеры замены параметров
в **существующих** секциях `config.toml`, не добавления повторных TOML-таблиц.

Нативное стекло macOS 26+, вместо текущего `blur = true`:

```toml
[window]
opacity = 0.75
blur = "macos-glass-regular"
```

Более прозрачный вариант: `blur = "macos-glass-clear"`. На старой macOS Rio
возвращается к обычному размытию. Стекло использует другой путь композитинга,
поэтому воспринимаемая прозрачность будет отличаться от текущего профиля.
Вернуть проверенный спокойный профиль: `opacity = 0.75`, `blur = true`,
`opacity-cells = false`. Это встроенный эффект Rio, не удалённый iglass.

Мягкий шлейф курсора, вместо `trail-cursor = false`:

```toml
[effects]
custom-mouse-cursor = false
trail-cursor = true
trail-cursor-color = "#73d0ff"
trail-cursor-opacity = 0.35
trail-cursor-decay = [60, 180]
trail-cursor-start-threshold = 2
```

Ещё поддерживаются фоновые картинки. Post-processing/CRT-фильтры зависят от сборки
с поддержкой wgpu, для стандартного нативного Metal-рендерера их не обещаем.
Рекомендуемый порядок экспериментов: сначала стекло, потом ненавязчивый шлейф.
Оба эффекта сейчас **не включены**, обычное размытие включено как в Ghostty.

## Herdr: ложная вложенная сессия

Rio, запущенный командой `open` из Herdr, может унаследовать идентификаторы
чужого pane. В `[shell]` они очищаются только для нового внешнего терминала.
Общий `dots-nu` и защита Herdr от настоящих вложенных запусков не изменяются.
В уже открытом старом shell окружение само не обновится. Открой новое окно Rio
или один раз выполни в старом Nushell, затем запусти `herdr`:

```nu
hide-env -i HERDR_ENV HERDR_BIN_PATH HERDR_SOCKET_PATH HERDR_WORKSPACE_ID HERDR_TAB_ID HERDR_PANE_ID
```

## Проверки и шрифты

Проверены запуск настоящего Nushell, доступность обоих шрифтов через CoreText,
Kitty graphics query и загрузка RGB-картинки с ответами `OK`. Полный `make test`
прошёл на повторном запуске. В первом запуске сработал существующий нестабильный
`TestPipeInputCancellation/select`, отдельно он прошёл пять раз с race detector.
AeroSpace не запускался параллельно активному Rift.

В Brewfile оставлены только используемые терминалами SF Mono и Symbols Nerd Font.
SF Symbols сохранён: это приложение-каталог, не шрифт. Неиспользуемые Martian Mono
и SketchyBar App Font удалены. SF Pro убран из Brewfile, но для удаления уже
установленного пакета из `/Library/Fonts` нужен администратор:

```sh
brew uninstall --cask font-sf-pro
```

Это не системная копия San Francisco в `/System/Library/Fonts`, она не затрагивается.
Резервные копии удалённых шрифтов и настроек iglass находятся локально вне Git:
`~/.local/state/dots/backups/2026-10-25-font-cleanup/` и
`~/.local/state/dots/backups/2026-10-25-remove-iglass/`.
