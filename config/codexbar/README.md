# CodexBar

Запуск: `codexbar-app` (ссылка устанавливается через `steps/terminal.yml`).
Обёртка поднимает настроенный прокси через `_codex_proxy_ensure`, выбирает источник Codex `cli` и передаёт окружение только приложению.
Системный прокси и глобальное окружение не меняются. Уже работающее приложение нужно завершить перед запуском с новым окружением.

Лимиты получает дочерний `codex app-server`; веб-дополнения OpenAI выключены.
Это не гарантия проксирования обновлений CodexBar или других провайдеров.
При запуске из Finder прокси самостоятельно не поднимается.

Обёртка сохраняет прочие настройки; учитывает `CODEXBAR_CONFIG`, абсолютный `XDG_CONFIG_HOME` и старый `~/.codexbar/config.json`.
Аккаунты и конфигурация остаются вне Git: [перенос](../../docs/PRIVATE.md).
