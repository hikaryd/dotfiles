# Задачи · Группы вкладок

Локальное расширение Manifest V3 для Brave / Chromium. Именует **существующие**
группы Kaiten + GitLab: `ATS-3823074 · Ускорить тесты`.

## Установка и запуск

1. Открыть `brave://extensions`, включить режим разработчика.
2. Нажать **Загрузить распакованное расширение**, выбрать эту папку.
3. Открыть расширение через меню 🧩, при желании закрепить на панели.
4. Выбрать окно с задачами и нажать **Выбрать**. Это разрешает изменение имён
   только в этом окне. До выбора расширение ничего не переименовывает.

**Автоматически** обновляет названия при изменении вкладок. **Обновить названия**
запускает ручной проход, в том числе при выключенной автоматике. Для горячей
клавиши открыть `brave://extensions/shortcuts`: расширение не занимает сочетание
по умолчанию.

Для своего имени отредактировать поле группы и нажать **Закрепить 🔒**.
Маркер хранится в самом имени группы, поэтому переживает смену идентификаторов
групп и перезапуск браузера. **Снять 🔒** разрешает последующее автоименование.

После полного перезапуска браузера **выбрать окно заново**: идентификаторы окон
непостоянны. Расширение намеренно не пытается угадать, какое окно изменять.

## Правила

- Номер **задачи ATS**, не номер MR и не внутренний ID карточки.
- Номер извлекается из `ATS-…`, семизначного префикса MR (`3770723: …`,
  `Feature/3770723 …`) или пути ветки GitLab.
- Короткое название предпочитается из Kaiten; без него — из MR.
- Из названия убираются префикс номера, служебные суффиксы, ведущие эмодзи и
  conventional-commit-префиксы.
- Два разных номера MR — конфликт. Ручное имя сохраняется; пустое имя или
  ранее сгенерированное имя-ссылка заменяется предупреждением `⚠ ATS-… / ATS-…`.
- Если ATS-номер неизвестен, явно показывается `Kaiten #3815206` (ID карточки)
  или `MR !42 / !43` (номера MR), без выдачи этих ID за номер задачи ATS.
- Одна задача может иметь MR в разных репозиториях. При отсутствии номера
  используется общий заголовок: `X5 Career · 2 MR`. Разные репозитории сами
  по себе не считаются конфликтом; номера MR остаются project-scoped.
- Если общего заголовка нет, для MR из разных репозиториев используется
  нейтральное `MR · 2 запроса`, без утверждения, что задачи разные.
- Страница авторизации без достоверных метаданных — имя сохраняется.
- Заголовки, похожие на URL, никогда не используются как описание; старые
  автоматически созданные имена-ссылки исправляются.
- При недоступном Kaiten ранее установленное хорошее название сохраняется.
- Меняется **только title группы**. Вкладки не создаются, не закрываются,
  не перемещаются и не перезагружаются; цвет и свёрнутость не меняются.

MVP распознаёт `kaiten.x5.ru` и `scm.x5.ru`; список находится в `naming.js`.
Он не читает DOM, поля карточек или содержимое MR. Если ATS-номера нет в
заголовках/пути ветки, расширение не угадывает его по числам в URL.

## Доступ и данные

Разрешения: `tabs` (названия, URL и принадлежность вкладок), `tabGroups`
(метаданные и переименование групп), `storage` (выбор окна и переключатель).

Нет host permissions, content scripts, cookies/history-разрешений, токенов,
запросов к серверам, аналитики или сторонних зависимостей. Chrome может описать
`tabs` как доступ к «истории просмотра»; здесь используется только метаинформация
открытых вкладок, не `chrome.history`. Адреса и заголовки страниц не сохраняются
в storage. Из query/hash читается только явный `card_id` на домене Kaiten;
параметры авторизации и return URL не разбираются. Фиксация имени — видимый
суффикс нативной группы.

## Проверка

Нужен Node 22+; установка npm-пакетов не требуется.

```sh
npm --prefix tools/task-tab-groups test
npm --prefix tools/task-tab-groups run check
```

`tests/browser_smoke.py` проверяет настоящее расширение в отдельном временном
профиле Brave через Playwright. Все HTTP(S)-ответы подменяются локальными
фикстурами; рабочие сайты и основной профиль не затрагиваются:

```sh
python tests/browser_smoke.py
```

`BRAVE_BINARY` позволяет выбрать исполняемый файл Brave. Для Python-проверки
нужен установленный Playwright.

## Структура

- `naming.js` — чистый модуль принятия решения по метаданным.
- `controller.js` — модуль выбранного окна, фиксации и безопасного применения.
- `background.js` — адаптер событий браузера, debounce и сообщения панели.
- `popup.*` — выбор окна, конфликты и редактирование фиксированного имени.
- `tests/` — контрактные тесты и изолированный браузерный smoke test.
