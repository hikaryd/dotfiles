Dots Proxy: локальный HTTP-прокси xray-core через VLESS вне РФ.
Системный VPN и proxy-настройки не меняются.

Настройка и фоновый запуск (macOS, после входа пользователя):
  dots-proxy --set-vless          # сохранить один vless:// конфиг
  dots-proxy --set-sub            # сохранить подписку и обновить серверы
  dots-proxy --install-service    # LaunchAgent, идемпотентно
  dots-proxy --uninstall-service  # убрать наблюдатель, оставить xray/соединения
  dots-proxy --stop               # убрать наблюдатель и остановить xray
  dots-proxy --status             # состояние процесса и доступность OpenAI

Потребители:
  dots-proxy --ensure             # только локальная готовность, без запуска/выбора
  dots-proxy --require-ready      # то же самое
  dots-proxy --print-env          # export-команды для текущего shell

Ручное управление (может оборвать текущие соединения):
  dots-proxy                      # выбрать сервер вручную
  dots-proxy --auto               # полный рейтинг по медиане 3 запросов до OpenAI
  dots-proxy --update             # обновить подписку
  dots-proxy --allow-insecure-sub --update
                                # аварийное обновление без проверки TLS
  dots-proxy --list               # показать серверы
  dots-proxy --daemon             # foreground-наблюдатель (обычно запускает launchd)

Наблюдатель подхватывает существующий исправный xray без перезапуска.
Каждые 30 секунд проверяет реальную страну через Cloudflare и OpenAI
через текущий listener. Рабочий маршрут не меняется ради скорости.
Одиночные ошибки не переключают сервер; после 3 последовательных сбоев
включается восстановление. Подтверждённый RU-выход останавливается сразу.
Для замены проверяются до 4 изолированных маршрутов параллельно;
выбирается любой первый рабочий вне РФ, без прямого/RU fallback.
Неизвестная страна не считается рабочей. OpenAI должен вернуть HTTP 200/401.
--ensure не ходит в сеть: проверяет PID, listener и свежесть проверки (90 с).
Без готового маршрута приложение не запускается напрямую.
Сбой настоящего маршрута и его замена могут оборвать текущий TCP-запрос.
Логи наблюдателя: ~/.config/xray-pi/supervisor.log (без секретов).
Имя backend pi, каталог xray-pi и LaunchAgent local.dots.pi-proxy сохранены
для совместимости действующих соединений Jcode, Jevgrep и Spotifast.
Pi CLI этим прокси не устанавливается и не запускается.
