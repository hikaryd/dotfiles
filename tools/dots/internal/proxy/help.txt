Pi Proxy — запускает xray-core как локальный HTTP-прокси для Pi
через VLESS-сервер на VPS или через VLESS-подписку.

Зачем:
  - корпоративный VPN продолжает работать для корпоративных ресурсов;
  - Pi ходит через локальный HTTP proxy 127.0.0.1:10810;
  - xray запускается как обычный процесс, а не как системный VPN.

Использование:
  pi-proxy                    # выбрать сервер и запустить xray
  pi-proxy --set-vless         # вставить один vless:// конфиг
  pi-proxy --set-sub           # сохранить URL подписки и обновить серверы
  pi-proxy --update            # обновить список серверов из подписки
  pi-proxy --allow-insecure-sub --update
                                 # аварийно обновить подписку без TLS-проверки сертификата
  pi-proxy --list              # показать все серверы
  pi-proxy --status            # проверить процесс и OpenAI через proxy
  pi-proxy --print-env         # вывести export-команды для текущего shell
  pi-proxy --run [args...]     # запустить pi CLI с proxy env
  pi-proxy --stop              # остановить xray

Примеры:
  pi-proxy --set-vless
  pi-proxy
  pi-proxy --status
  pi-proxy --allow-insecure-sub --update
  pi-proxy --run
  pi-proxy --run -p "ping"
